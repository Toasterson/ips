# V1 Release Pipeline and IPS/SMF Package

**Date:** 2026-09-23
**Status:** Active
**Issues:** [#41](https://code.aopc.cloud/OpenIndiana/ips/issues/41) (IPS/SMF part only), [#8](https://code.aopc.cloud/OpenIndiana/ips/issues/8)
**Decision:** [ADR-005](../decisions/005-release-pipeline-and-ips-packaging.md)

## Goal

Every release tag, whether alpha, beta, rc or GA, runs one tested pipeline.
The pipeline produces the following:

- an installable OpenIndiana `.p5p` for `package/pkg6/depotd` with an SMF service
- tarballs for Linux and illumos
- exact tag-to-commit and checksum provenance

Pre-releases are published as prereleases. GA releases stay drafts for a
maintainer.

## Out of scope

- TLS and ACME, and their configuration keys (#41, other slice).
- Full mdBook and man page set (#30). Only `pkg6depotd(8)` ships here.
- Import automation (#38).
